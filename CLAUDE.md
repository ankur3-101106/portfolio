## What This Is

A personal portfolio + study-notes site built on Docusaurus 3 (classic preset) with React 19, deployed to GitHub Pages (`https://ankur3-101106.github.io`, `baseUrl: '/'`). Node >= 20 required.

## Commands

```bash
bun install          # deps (bun.lock); npm install also works (package-lock.json kept in sync)
npm run start        # dev server with HMR at http://localhost:3000
npm run build        # production build — also the de facto "test"
npm run serve        # serve the production build locally
npm run clear        # wipe Docusaurus/webpack cache when builds behave oddly
```

There are no test suites or linters configured. **`npm run build` is the only verification** — run it after content or config changes. Note `onBrokenLinks: 'throw'` in `docusaurus.config.js`: any broken internal link or doc reference fails the build.

## Architecture

The site has two independent surfaces:

### 1. Portfolio landing page (custom React app)

`src/pages/index.js` composes section components from `src/components/` (Hero, About, Experience, Projects, Certifications, Contact) into a single animated page. Animation stack: GSAP + ScrollTrigger (registered in `index.js` and hooks), Lenis smooth scrolling driven by the GSAP ticker, anime.js, and canvas effects (Matrix rain). Reusable GSAP patterns live as hooks in `src/hooks/` (useSmoothScroll, useScrollTrigger, useStaggerReveal, useTextScramble).

Styling is plain CSS files sitting next to each component (e.g. `Hero.css`) plus global Infima theme overrides in `src/css/custom.css`.

Theme swizzles in `src/theme/`:
- `Layout/index.js` wraps every page layout to mount `ScrollProgress`
- `NavbarItem/ComponentTypes.js` registers the `custom-clock` navbar item type referenced in `docusaurus.config.js`

### 2. Notes (docs plugin)

Content lives in `docs/`, organized by semester → subject → units:
```
docs/Sem-5/MFW/u1.mdx ... u6.mdx   # one file per course unit
docs/Sem-5/MFW/_category_.json     # sidebar label/position for the subject
```

- The sidebar is fully autogenerated from folder structure (`sidebars.js` uses `{type: 'autogenerated'}`) — do not hand-edit sidebar entries; control ordering via `_category_.json` and `sidebar_position` frontmatter (unit files use `sidebar_position: N` matching the unit number).
- Math renders via remark-math/rehype-katex (`$...$`, `$$...$$`; KaTeX CSS loaded from CDN in config).
- Diagrams via fenced ```` ```mermaid ```` blocks (theme-mermaid enabled).
- These are prose-heavy `.mdx` files: escape bare `<` and `{` in text/code or MDX parsing fails.

Blog posts follow standard Docusaurus conventions in `blog/` (date-prefixed filenames, `authors.yml`, `tags.yml`). Config sets `onInlineTags`/`onInlineAuthors`/`onUntruncatedBlogPosts` to `'warn'`, so keep tags/authors referenced properly and posts truncated.

Local search comes from `@easyops-cn/docusaurus-search-local` (configured in the plugins array, not the themeConfig navbar slot).
